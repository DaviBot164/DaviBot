# Private AI: rate-limit recovery and reply guidance

429 errors now display a bounded numeric wait from Groq's retry-after header. If absent, exhausted request/token counters may supply their documented reset duration. Malformed, missing, excessively large or secret-looking values are never echoed; an unknown wait remains unknown. Raw provider bodies are not read for diagnostics. A known wait blocks new requests locally until it elapses, including across private scenario resets, so these blocked attempts do not consume the 30-request local cap. Provider failures still count as attempts. No automatic retries, sleeping jobs, fallback engines or paid-plan changes are added. A restart or another replica has separate in-process state.

The rate-limit report explains that later lines were not sent. To resume, wait, then submit only unfinished lines using the same channel/persona without a seed. Seed intentionally resets the private scenario; retained history still expires after ten minutes and has the existing message/character bounds. Resuming is not a new inference retry performed automatically. Other callers may consume organization quota, so a provider wait is guidance rather than a guarantee of availability.

A small explicit preference record now accompanies retained private history: listening, short replies, no fox metaphors, and avoiding unnecessary questions. Simple explicit English cues set/clear these flags; fresh-start cues reset them. Failed turns do not commit preference changes. Scenario seed/reset, persona/channel isolation and expiry apply as before. This is a bounded preference aid, not general semantic memory. Reported/quoted whole commands are not interpreted as the speaker's preference. The prompt asks the model to resolve any incomplete lexical cue from the actual dialogue. Preferences never change identity, permissions, billing, tools or the public bot.

The prompt also discourages unsolicited tactical advice, invented cooldowns/movement abilities, empty acknowledgements, invented emotions and fox-sneak-style metaphors. Advice should use only the stated issue. These instructions still require live quality evaluation; mocked tests cannot establish that a language model will obey. No output text is silently replaced with a canned reply or truncated solely for style.

For live regression use short 3–4 turn batches, then continue without a seed to reach recall questions. Wait when the provider reports a limit rather than restarting all chains. Check listening/advice permission, specific short acknowledgements and facts independently. The server glossary and public built-in chat are unchanged. No command registration, schema or dependency changes.

Header meanings checked against https://console.groq.com/docs/rate-limits : retry-after in seconds, token reset for TPM, request reset for RPD.
