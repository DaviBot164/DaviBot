# Short, natural replies

Knowledge answers use name — linked member/role/channel, followed by the full saved explanation when present. Other glossary entries use name: explanation; custom replies keep their complete saved text. No blanket character truncation changes an explanation's meaning. Saved records and IDs are unchanged. Save/remove confirmations are shorter.

The private Groq system prompt now asks for one concise sentence by default, a second when useful, and more detail when needed for accuracy or explicitly requested. It discourages repeating the user's whole message, service endings, unnecessary follow-up questions, theatrical metaphors and internal record narration. Script-like reply examples were removed. These are instructions, not a guarantee of model compliance; real AI regression remains necessary. Public live chat still uses built-in rules, not Groq. Existing built-in replies, cooldowns, permissions, public XP and help embeds are retained.

No schema, dependency or slash-command registration changes are needed. After deployment ask who is tomy and a glossary term with an explanation. Check linked identity plus full explanation, and compare an owner/member Groq test when quota permits.
