# Discord phrase learning: controls and suggestions

The existing owner-only /kitsune teach command now has 25 supported meanings. Four additions: continue (carry on the current topic), stop (end the conversation), restart (fresh start), change topic (leave the current subject). Existing stored meanings and guild scope are unchanged. This teaches approved phrase aliases, not model weights or arbitrary free-form definitions. It affects built-in live dialogue; private built-in tests still intentionally exclude server aliases, and Groq has its own prompt/history.

Example: /kitsune teach phrase:go ahead meaning:continue. Repeating teach with the same phrase updates its saved meaning, invalidates the guild cache, and removes it from the unknown list in the existing transaction. Built-in meanings cannot be overwritten.

Continue uses the existing follow-through resume handler for supported active threads; otherwise it keeps the topic and invites the next contribution. Without usable context it asks what to continue. It never accepts a suggestion, decides a choice, resumes declined advice or authorizes an external action. Addressing/reply/implicit timeout boundaries still apply.

The phrase option in teach/forget/dismiss suggests saved phrases. Teach searches both unknown and learned; forget only learned; dismiss only unexpired unknown. Matching is a literal normalized prefix, scoped to the invoking guild, with at most 25 results and an 1800ms suggestion deadline. English prefixes need at least two valid characters; an empty field can show initial suggestions. If unavailable, type the phrase manually. Values longer than Discord's 100-character autocomplete value limit are omitted, not truncated; manual phrase entry retains the 160-character limit. Only the actual owner in a guild can receive suggestions; unauthorized users receive an empty list. No chat is sent to AI for this feature.

After installing, commit/push/deploy and run node deploy-commands.js once to register the new meaning choices and autocomplete flags. This does not add a top-level command or database table. Test live by teaching go ahead as continue, starting a music conversation, then using go ahead. Use /kitsune learned to inspect and /kitsune forget to remove. Existing slash defaults keep administrative visibility and actual owner authorization.

Offline verification uses mocked repositories and Discord, plus the real parser/response paths for learned aliases, thread resume, stop/reset/topic controls, protected built-in meanings and context boundaries. No live database, Discord or provider requests are made.
